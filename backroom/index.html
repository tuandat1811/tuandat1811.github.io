How do I get a token?
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → {{ site.admin.repo }}.
  3. Permissions: Contents → Read and write. Optional: Pages → Read (to see build status).
  4. Set an expiration date, generate, and paste it here.

The token stays in this browser only — this tab by default, or this device if you tick “Remember”. Lock up when you're done on a shared computer.
